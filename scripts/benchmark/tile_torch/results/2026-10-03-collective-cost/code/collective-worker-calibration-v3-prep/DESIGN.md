# Frozen experimental numeric worker profile v3

This small revision is specified before its first fit and does not read independent heldout outcomes. It keeps the original two completed training summaries and every observation, including prefixes, regressions, and default rechecks. The v1 and v2 scripts and reports remain immutable.

The allowed worker candidates are 0 and 8. Prefix collectives and unmeasured MINIMUM algebra select 0. Strict math, no structural rewrite, SM89 with 24 SMs and warp32, and the declared CUDA13.4 toolchain define the current optional profile boundary. It is disabled by default and has **uncalibrated confidence**. Profile deployment must verify compatible runtime facts; stored receipts alone do not prove the running compiler or device identity.

All features come from shared collective IR analysis: logical programs per SM, largest materialized Tile, peak explicit Tile bytes per warp of FP32, element work per summed collective input volume, largest contribution width per warp, summed independent elements, SUM/MAXIMUM fractions of collective input volume, and nominal load-plus-store bytes per FP32 collective input volume. Features 0..5 and 8 apply log2(1+x); fractions 6/7 do not. See `feature_vector` for the exact binary64 equations. These are logical predictors, not measured registers, occupancy, physical traffic, or proof of causal mechanisms. No operation label, fixture name, dtype label or external shape lookup enters the model.

The weighted regression tree has maximum depth 2 and at least two distinct geometry groups per leaf. Each geometry group has total weight one, so repeated measurements and dtype/kind variants do not dominate. Midpoint thresholds minimize squared log(worker8/default0) error with deterministic feature-order and lower-threshold tie breaking. The full geometric group is removed before each LOGO fit. Its outcomes cannot affect that fold's training or decision.

An optional worker8 decision requires a leaf mean strictly below log(0.95), a point prediction of over 5% lower event time. There is no calibrated uncertainty gate and no local multidimensional support-box gate. Full ranges, every LOGO residual, selected regressions, timing spread, and default drift remain explicit diagnostics. This removes v2's near-universal box rejection without pretending that uncertainty has improved. Training-fit choices are not evidence of generalization. Freeze the complete script, profile nodes, and parity fixture before independent heldout validation; do not refit on that heldout packet.
