# Ray Query Support for CUDA LLVM Codegen

## Overview

This document describes the implementation strategy for adding ray query support to the CUDA LLVM codegen path. The goal is to transform ray query loops from XIR into LLVM IR that's compatible with OptiX's ray tracing pipeline.

## Architecture

### Current Pipeline

```
XIR (RayQueryLoopInst, RayQueryDispatchInst)
    ↓
LLVM IR (with luisa.ray.query.* pseudo-intrinsics)
    ↓
RayQueryLoopExtraction Pass
    ↓
Extracted LLVM function with pseudo-intrinsics
    ↓
Handler Intrinsic Lowering Pass
    ↓
OptiX Entry Point Generation (__anyhit__, __intersection__)
    ↓
OptiX-compatible LLVM IR
    ↓
PTX Generation
    ↓
OptiX Pipeline (__raygen__main, __anyhit__ray_query, __intersection__ray_query)
```

### OptiX Program Structure

The generated PTX must contain these entry points:

1. **`__raygen__main`** - Kernel entry point that initiates ray queries (generated from XIR kernel)
2. **`__anyhit__ray_query`** - Triangle intersection handler (generated by LLVM codegen)
3. **`__intersection__ray_query`** - Procedural intersection handler (generated by LLVM codegen)

**Note**: The `__anyhit__` and `__intersection__` programs are **generated by our LLVM codegen**, NOT taken from `cuda_device_resource.h`. The CUDA device library serves as a reference but we generate equivalent functionality directly in LLVM IR.

### Important Implementation Notes

#### Function Identification via Intrinsic Scanning

**CRITICAL**: Never rely on fragile string matching or stored pointers to identify ray query functions. Functions can be:
- **Deleted** by dead code elimination
- **Merged** by mergefunctions pass
- **Moved/renamed** by optimization passes

**Solution**: Dynamically scan for functions containing `luisa.ray.query.dispatch` intrinsic calls:

```cpp
[[nodiscard]] bool _is_ray_query_handler(llvm::Function *func) noexcept {
    if (func == nullptr || func->isDeclaration()) return false;
    
    for (auto &block : *func) {
        for (auto &inst : block) {
            if (auto *call = llvm::dyn_cast<llvm::CallInst>(&inst)) {
                auto *callee = call->getCalledFunction();
                if (callee && callee->getName() == "luisa.ray.query.dispatch") {
                    return true;
                }
            }
        }
    }
    return false;
}

// Usage: Scan dynamically right before processing
llvm::SmallVector<llvm::Function *, 8> handlers;
for (auto &func : *module) {
    if (_is_ray_query_handler(&func)) {
        handlers.push_back(&func);
    }
}
```

**Benefits**:
- Handles dead code elimination gracefully (deleted functions simply won't be found)
- No risk of dangling pointers
- Self-healing: always finds current state of module
- Works regardless of function renaming or optimization

**Internal Linkage for Optimization**:
Mark extracted functions with `InternalLinkage` to allow LLVM to optimize unused arguments:
```cpp
extracted_func->setLinkage(llvm::Function::InternalLinkage);
// Run optimization passes here - LLVM can remove unused args
// Then transform for ray query handling
```

**Ordering**:
1. Extract with `InternalLinkage`
2. Run optimization passes (may delete dead functions)
3. **Scan** for surviving handlers
4. Transform handlers
5. Generate entry points
6. Mark `AlwaysInline` for final optimization

#### Private Member Access

Ray query implementation methods need access to private members (`_ray_query_functions`, `_llvm_module`, etc.). Implement these methods in `cuda_codegen_llvm_impl.cpp` rather than separate files to avoid friend declarations or complex access patterns.

## Pseudo-Intrinsics

The LLVM codegen translates XIR ray query instructions into pseudo-intrinsics:

| Intrinsic | Purpose | Transformed To |
|-----------|---------|----------------|
| `luisa.ray.query.initialize` | Initialize ray query state | `luisa.ray.query.spawn` + context setup |
| `luisa.ray.query.spawn` | Start ray traversal | OptiX trace call with encoded context |
| `luisa.ray.query.proceed` | Continue to next candidate | `luisa.ray.query.dispatch` in extracted handler |
| `luisa.ray.query.dispatch` | Dispatch to next iteration | Loop back or return from handler |
| `luisa.ray.query.state` | Get current state (0=exit, 1=surface, 2=procedural) | Hit type decode |
| `luisa.ray.query.world.space.ray` | Get world space ray | `lc_ray_query_world_ray()` call |
| `luisa.ray.query.surface.candidate.hit` | Get triangle hit info | `lc_ray_query_triangle_candidate()` call |
| `luisa.ray.query.procedural.candidate.hit` | Get procedural hit info | `lc_ray_query_procedural_candidate()` call |
| `luisa.ray.query.committed.hit` | Get committed hit | `lc_ray_query_decode_hit()` call |
| `luisa.ray.query.commit.surface.hit` | Commit triangle hit | Set `result.committed = true` |
| `luisa.ray.query.commit.procedural.hit` | Commit procedural hit | Set `result.committed = true` + `result.t_hit = t` |
| `luisa.ray.query.terminate` | Terminate traversal | Set `result.terminated = true` |

## Implementation Phases

### Phase 1: Ray Query Loop Extraction (Simplified Approach)

**File**: `cuda_codegen_llvm_impl.cpp` - Modify `RayQueryLoopExtraction` pass

**Strategy**: Extract the **entire** ray query loop as one function and let LLVM optimize it, rather than splitting into separate handlers.

```cpp
// Current approach extracts the whole loop:
// 1. Find luisa.ray.query.proceed call
// 2. Find containing loop via LoopInfo
// 3. Find dominating luisa.ray.query.initialize
// 4. Extract entire loop into new function
// 5. Let LLVM optimize (constant folding eliminates unreachable states)

class RayQueryLoopExtraction : public llvm::PassInfoMixin<RayQueryLoopExtraction> {
private:
    [[nodiscard]] bool _extract_ray_query_loops(llvm::Module &module, 
                                                 llvm::ModuleAnalysisManager &module_am) noexcept {
        // Find all proceed calls
        auto proceed_func = module.getFunction(
            CUDACodegenLLVMImpl::llvm_ray_query_intrinsic_name_proceed);
        if (!proceed_func) return false;
        
        while (!proceed_func->user_empty()) {
            auto call = llvm::dyn_cast<llvm::CallInst>(*proceed_func->user_begin());
            auto func = call->getFunction();
            auto &func_am = module_am.getResult<llvm::FunctionAnalysisManagerModuleProxy>(module)
                               .getManager();
            auto &dom_tree = func_am.getResult<llvm::DominatorTreeAnalysis>(*func);
            auto &loop_info = func_am.getResult<llvm::LoopAnalysis>(*func);
            
            // Find loop containing proceed
            auto loop = loop_info.getLoopFor(call->getParent());
            
            // Extract entire loop
            auto assumption_cache = func_am.getCachedResult<llvm::AssumptionAnalysis>(*func);
            llvm::CodeExtractor extractor{loop->getBlocks(), &dom_tree, false, 
                                          nullptr, nullptr, assumption_cache};
            llvm::CodeExtractorAnalysisCache cache{*func};
            auto extracted_func = extractor.extractCodeRegion(cache);
            
            extracted_func->setName("ray.query.extracted");
            extracted_func->addFnAttr(llvm::Attribute::AlwaysInline);
            
            // Mark for processing
            _ray_query_functions.insert(extracted_func);
        }
        return true;
    }
    
    llvm::DenseSet<llvm::Function *> _ray_query_functions;
};
```

**Benefits of this approach**:
- Simpler implementation
- LLVM constant folding eliminates unreachable states automatically
- Single extraction vs. multiple handler extractions

### Phase 2: Handler Intrinsic Lowering

**File**: `cuda_codegen_llvm_impl_rq.cpp`

Transform pseudo-intrinsics in extracted function to device library calls:

```cpp
void CUDACodegenLLVMImpl::_lower_ray_query_handler(llvm::Function *handler) {
    llvm::IRBuilder<> builder{llvm_context_};
    
    for (auto &block : handler->getBasicBlockList()) {
        for (auto inst_it = block.begin(); inst_it != block.end(); ) {
            auto &inst = *inst_it++;
            
            if (auto call = llvm::dyn_cast<llvm::CallInst>(&inst)) {
                auto callee = call->getCalledFunction();
                if (!callee) continue;
                
                auto name = callee->getName();
                if (name == llvm_ray_query_intrinsic_name_world_space_ray) {
                    _replace_with_device_call(call, "lc_ray_query_world_ray");
                }
                else if (name == llvm_ray_query_intrinsic_name_surface_candidate_hit) {
                    _replace_with_device_call(call, "lc_ray_query_triangle_candidate");
                }
                else if (name == llvm_ray_query_intrinsic_name_procedural_candidate_hit) {
                    _replace_with_device_call(call, "lc_ray_query_procedural_candidate");
                }
                else if (name == llvm_ray_query_intrinsic_name_commit_surface_hit) {
                    // Store to result.committed
                    _store_result_field(handler, call, /*committed*/ true);
                }
                else if (name == llvm_ray_query_intrinsic_name_commit_procedural_hit) {
                    // Store to result.committed and result.t_hit
                    _store_procedural_commit(handler, call);
                }
                else if (name == llvm_ray_query_intrinsic_name_terminate) {
                    _store_result_field(handler, call, /*terminated*/ true);
                }
                else if (name == llvm_ray_query_intrinsic_name_proceed) {
                    // Replace with dispatch intrinsic
                    _replace_intrinsic(call, llvm_ray_query_intrinsic_name_dispatch);
                }
            }
        }
    }
}
```

```cpp
void CUDACodegenLLVMImpl::_generate_intersection_program(
    const llvm::DenseVector<llvm::Function *> &handlers) {
    
    auto void_type = llvm::Type::getVoidTy(llvm_context_);
    auto func_type = llvm::FunctionType::get(void_type, {}, false);
    auto func = llvm::Function::Create(func_type, llvm::Function::ExternalLinkage,
                                       "__intersection__ray_query", llvm_module_.get());
    func->setCallingConv(llvm::CallingConv::PTX_Kernel);
    
    llvm::IRBuilder<> builder{llvm_context_};
    auto entry_block = llvm::BasicBlock::Create(llvm_context_, "entry", func);
    builder.SetInsertPoint(entry_block);
    
    // Set payload types
    _call_optix_set_payload_types(builder, LC_PAYLOAD_TYPE_RAY_QUERY);
    
    // Decode query ID and context from payload registers
    auto r0 = _call_optix_get_payload(builder, 0);
    auto r1 = _call_optix_get_payload(builder, 1);
    
    auto query_id = builder.CreateLShr(r0, 24);
    auto ctx_hi = builder.CreateAnd(r0, 0xffffff);
    auto ctx_ptr = builder.CreateIntToPtr(
        builder.CreateOr(
            builder.CreateShl(builder.CreateZExt(ctx_hi, builder.getInt64Ty()), 32),
            builder.CreateZExt(r1, builder.getInt64Ty())
        ),
        builder.getPtrTy()
    );
    
    // Create switch to dispatch to correct handler
    auto switch_inst = builder.CreateSwitch(query_id, 
                                             llvm::BasicBlock::Create(llvm_context_, "default", func),
                                             handlers.size());
    
    // Add cases for each handler
    for (size_t i = 0; i < handlers.size(); ++i) {
        auto case_block = llvm::BasicBlock::Create(llvm_context_, 
                                                    "handler_" + std::to_string(i), func);
        switch_inst->addCase(builder.getInt32(i), case_block);
        builder.SetInsertPoint(case_block);
        
        // Call handler with context pointer
        builder.CreateCall(handlers[i], {ctx_ptr});
        
        // Report intersection if committed
        // This requires extracting the committed/terminated/t_hit from handler
        // ... implementation details
        
        builder.CreateRetVoid();
    }
}
```

### Phase 4: Context Management

**File**: `cuda_codegen_llvm_impl_rq_context.cpp` (new)

Follow naming conventions: `_private_method`, `ClassName`, `variable_name`

```cpp
// Context struct for captured variables
struct RayQueryContextInfo {
    llvm::StructType *struct_type;
    llvm::DenseMap<llvm::Value *, uint32_t> member_indices;
    bool has_captures;
};

RayQueryContextInfo CUDACodegenLLVMImpl::_create_ray_query_context(
    const llvm::DenseSet<llvm::Value *> &captured_values) {
    
    if (captured_values.empty()) {
        return {nullptr, {}, false};
    }
    
    // Separate pointers from scalars
    llvm::SmallVector<llvm::Value *, 8> resources;
    llvm::SmallVector<llvm::Value *, 8> scalars;
    
    for (auto *value : captured_values) {
        if (value->getType()->isPointerTy()) {
            resources.push_back(value);
        } else {
            scalars.push_back(value);
        }
    }
    
    // Sort scalars by alignment (descending)
    std::sort(scalars.begin(), scalars.end(),
        [](llvm::Value *a, llvm::Value *b) {
            return _get_type_alignment(a->getType()) > _get_type_alignment(b->getType());
        });
    
    // Build struct type
    llvm::SmallVector<llvm::Type *, 16> member_types;
    for (auto *value : resources) {
        member_types.push_back(value->getType());
    }
    for (auto *value : scalars) {
        member_types.push_back(value->getType());
    }
    
    auto struct_type = llvm::StructType::create(llvm_context_, member_types, "RayQueryCtx");
    
    // Map values to indices
    llvm::DenseMap<llvm::Value *, uint32_t> indices;
    uint32_t idx = 0;
    for (auto *value : llvm::concat<llvm::Value *>(resources, scalars)) {
        indices[value] = idx++;
    }
    
    return {struct_type, indices, true};
}

void CUDACodegenLLVMImpl::_emit_context_store(llvm::IRBuilder<> &builder,
                                               llvm::Value *ctx_ptr,
                                               llvm::StructType *ctx_type,
                                               const llvm::DenseMap<llvm::Value *, uint32_t> &indices,
                                               llvm::Value *value) {
    if (!indices.contains(value)) return;
    
    auto idx = indices.lookup(value);
    auto gep = builder.CreateStructGEP(ctx_type, ctx_ptr, idx);
    builder.CreateStore(value, gep);
}

llvm::Value *CUDACodegenLLVMImpl::_emit_context_load(llvm::IRBuilder<> &builder,
                                                      llvm::Value *ctx_ptr,
                                                      llvm::StructType *ctx_type,
                                                      const llvm::DenseMap<llvm::Value *, uint32_t> &indices,
                                                      llvm::Value *value) {
    if (!indices.contains(value)) return value;
    
    auto idx = indices.lookup(value);
    auto gep = builder.CreateStructGEP(ctx_type, ctx_ptr, idx);
    return builder.CreateLoad(ctx_type->getElementType(idx), gep);
}
```

```cpp
void CUDACodegenLLVMImpl::_emit_kernel_ray_query_call(
    llvm::IRBuilder<> &builder,
    llvm::Value *ray_query_obj,
    uint32_t query_id,
    const RayQueryContextInfo &ctx_info) {
    
    llvm::Value *ctx_ptr = nullptr;
    
    if (ctx_info.has_captures) {
        // Allocate context on stack
        auto ctx_alloca = builder.CreateAlloca(ctx_info.struct_type);
        ctx_ptr = builder.CreateBitCast(ctx_alloca, builder.getPtrTy());
        
        // Store captured values (implement actual capture logic)
        for (auto &[value, idx] : ctx_info.member_indices) {
            auto gep = builder.CreateStructGEP(ctx_info.struct_type, ctx_alloca, idx);
            builder.CreateStore(value, gep);
        }
    } else {
        // No captures, use null
        ctx_ptr = llvm::Constant::getNullValue(builder.getPtrTy());
    }
    
    // Encode query ID and context pointer for payload
    auto ctx_int = builder.CreatePtrToInt(ctx_ptr, builder.getInt64Ty());
    auto ctx_high = builder.CreateLShr(ctx_int, 32);
    auto ctx_high_masked = builder.CreateAnd(ctx_high, 0xffffff);
    auto query_id_shifted = builder.getInt32(query_id << 24);
    auto r0 = builder.CreateOr(query_id_shifted, 
                               builder.CreateTrunc(ctx_high_masked, builder.getInt32Ty()));
    auto r1 = builder.CreateTrunc(ctx_int, builder.getInt32Ty());
    
    // Call lc_ray_query_trace
    _call_ray_query_trace(builder, ray_query_obj, query_id, ctx_ptr, r0, r1);
    
    // Load back modified captured values
    if (ctx_info.has_captures) {
        for (auto &[value, idx] : ctx_info.member_indices) {
            // Check if value is written in handler, then load it back
            if (_is_value_written_in_handler(value)) {
                auto gep = builder.CreateStructGEP(ctx_info.struct_type, ctx_alloca, idx);
                auto loaded = builder.CreateLoad(ctx_info.struct_type->getElementType(idx), gep);

            }
        }
    }
}
```

### Phase 6: Pass Pipeline

**File**: `cuda_codegen_llvm_impl.cpp`

Run passes in correct order:

```cpp
luisa::string CUDACodegenLLVMImpl::generate(const xir::Module &xir_module) noexcept {
    // Phase 1: Initial LLVM IR generation from XIR
    _analyze_ray_tracing_usage(xir_module);
    for (auto func : xir_module.function_list()) {
        if (auto def = func->definition()) {
            _translate_function(def);
        }
    }
    
    // Phase 2: Run initial optimization pass
    _run_optimization_passes();
    
    // Phase 3: Ray Query transformation passes
    if (_rt_analysis.uses_ray_query) {
        // 3a. Extract ray query loops
        llvm::ModulePassManager rq_mpm;
        rq_mpm.addPass(detail::RayQueryLoopExtraction{});
        
        // 3b. Lower intrinsics in extracted functions
        rq_mpm.addPass(RayQueryHandlerLoweringPass{});
        
        // 3c. Generate OptiX entry points
        rq_mpm.addPass(RayQueryEntryPointGenerationPass{});
        
        llvm::ModuleAnalysisManager rq_mam;
        // Register required analyses
        rq_mam.registerPass([] { return llvm::LoopAnalysis(); });
        rq_mam.registerPass([] { return llvm::DominatorTreeAnalysis(); });
        rq_mam.registerPass([] { return llvm::AssumptionAnalysis(); });
        
        rq_mpm.run(*llvm_module_, rq_mam);
    }
    
    // Phase 4: Final optimization pass
    _run_optimization_passes();
    
    // Phase 5: Generate PTX
    return _generate_ptx();
}
```

### State Machine Optimization

The extracted loop contains a switch on `luisa.ray.query.state()`:

```llvm
; In extracted handler:
%state = call i8 @luisa.ray.query.state()
switch i8 %state, label %exit [
  i8 1, label %surface_handler
  i8 2, label %procedural_handler
]
```

LLVM's constant propagation will eliminate the switch if we know the state is constant in a particular context. The LLVM optimization passes after extraction will:
1. Constant fold the switch
2. Eliminate dead code (unreachable states)
3. Simplify the CFG

## Context Encoding

Query ID and context pointer are encoded in OptiX payload registers (2 registers for ray query):

```
Payload Register 0 (r0):
  Bits [31:24] - Query ID (0-31)
  Bits [23:0]  - High 24 bits of context pointer

Payload Register 1 (r1):
  Bits [31:0]  - Low 32 bits of context pointer
```

Encoding in kernel:
```cpp
auto ctx_u64 = reinterpret_cast<uint64_t>(ctx_ptr);
auto r0 = (query_id << 24) | ((ctx_u64 >> 32) & 0xffffff);
auto r1 = ctx_u64 & 0xffffffff;
```

Decoding in `__anyhit__` / `__intersection__`:
```cpp
auto query_id = (payload0 >> 24) & 0xff;
auto ctx_ptr = ((payload0 & 0xffffff) << 32) | payload1;
```

## Code Style Guidelines

Follow existing llvm_codegen conventions:

- **Classes**: `ClassName` (e.g., `RayQueryLoopExtraction`)
- **Private members/methods**: `_private_member`, `_private_method()`
- **Public methods**: `public_method()`
- **Variables**: `variable_name`
- **LLVM values**: `llvm_value_name` prefix
- **Constants**: `kConstantName`

Example:
```cpp
class RayQueryHandlerLowering : public llvm::PassInfoMixin<RayQueryHandlerLowering> {
private:
    llvm::DenseSet<llvm::Function *> _ray_query_handlers;
    
    void _lower_handler(llvm::Function *handler);
    void _replace_intrinsic(llvm::CallInst *call, llvm::StringRef new_name);
    
public:
    llvm::PreservedAnalyses run(llvm::Module &module, 
                                llvm::ModuleAnalysisManager &module_am) noexcept;
};
```

## Notes

- Maximum 32 ray queries per kernel (limited by query ID encoding in 8 bits)
- Handlers marked with `AlwaysInline` attribute for performance
- Use `_get_inline_asm()` helper for all OptiX calls with proper side effect flags
- Follow opaque pointer semantics (LLVM 15+): use `builder.getPtrTy()`
- The old `cuda_device_resource.h` is a reference only; we generate all code in LLVM IR
- Extraction is done at LLVM level, not XIR level
