LuisaCompute documentation
==========================

LuisaCompute is a high-performance cross-platform computing framework for graphics and beyond.

Start with the build guide and tutorials, choose a programming model, then
follow the implementation references or measured performance reports as needed.
Tile programming is an experimental execution-first DSL within the same framework;
it shares Luisa Runtime rather than introducing a separate application stack.
