# Performance and validation

This section contains measured implementation evidence, not language promises.
Keep a result tied to its device, datatype, shape, compiler route, numerical
policy and timing method. Correctness coverage and performance coverage are
different claims.

The Tile summary links to route-specific comparisons, correctness
investigations and historical checkpoints; raw benchmark records remain with
the benchmark tools. The compiler and backend validation archive collects
dated regression investigations, preserving their original evidence scope.
